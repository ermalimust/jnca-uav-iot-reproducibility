# P18 formal independent action-effects study

Frozen design before formal outcome generation, 2026-09-14. Machine-readable `protocol.json` gives every scenario, handler, timing and inference setting. Engineering-only runs 9001/9002 check implementation and accounting; no handler/environment parameters are chosen from their outcome ranking. Necessary bug fixes are recorded before formal binding, and any post-binding change requires an amendment and complete affected rerun.

The experiment tests action mechanisms in an independent ns-3 Wi-Fi protocol model. It does not test a diagnostic or a generated policy. Five fixed handlers are applied once to identical network prefixes in eight W/M/V factorial scenarios and 16 paired RNG runs: 640 runs. The dataset's first 20 seconds of Parrot control UDP emissions supplies 800 injection times and the original payload lengths. The source capture is a public transport-emission record, not an observation of internal command creation. Video and external offered schedules and the UAV trajectory are explicitly synthetic and fixed independently of the chosen action.

All sources run from simulation seconds 1 to 21; the command occurs at 11 and becomes effective at 11.001. Primary outcomes use the [11,21) **offered** packet cohorts and sinks run until 23. Deadline miss includes every C2 packet not received within 10ms of its offer, including eventual late and horizon-unreceived packets. Video delivery uses all originally offered bytes as its denominator, including shaping drops; received-window Mbps is reported separately. Finite-horizon non-delivery is not automatically permanent loss. All recorded packet identifiers are simulation tags and add no wire bytes.

The trace records application offer, successful socket submission, first destination receive, duplicate receive, shaper drops, failed socket submissions, PHY transmission attempts and MAC terminal events. Prefix snapshots are taken before the command and must match byte for byte across all actions for each scenario/run. Packets offered before the command can receive different later outcomes; their final rows are not used as proof of an identical prefix. In-flight frames and existing MAC queues are retained at intervention. Changing EDCA bounds follows ns-3's setter semantics and does not rebuild the device. Fallback changes new C2 packets' IP DS field to select the voice AC and its actual QoS TID is checked.

Eight primary paired tests compare each non-Observe action with Observe on C2 deadline-miss fraction and demand-normalized video delivery. First average the eight fixed scenarios within each RNG run; the 16 paired run differences are the inferential blocks. Enumerate all 65,536 signs under the stated sign-exchangeability null. Use 10,000 common block bootstrap resamples for pointwise percentile intervals. Publish all eight directions, raw p-values and within-family/pooled101 adjustments; retain the original 93 raw hypotheses exactly. Per-scenario and secondary metrics are descriptive. The repeats are simulations conditional on one public arrival case, not independent real flights.

Reviewer mapping: R1 C2 concerns independent action consequences; R1 C6 concerns service abstraction; R3 C1 concerns a result determined by one assigned benchmark; R2 M3/R4 M1 concern the mechanism and empirical basis of the service environment. New protocol evidence strengthens those specific aspects. The original demand for complete operational posterior matching remains separately assessed.
