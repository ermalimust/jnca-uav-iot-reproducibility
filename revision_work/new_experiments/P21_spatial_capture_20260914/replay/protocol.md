# 固定模型後的 ns-3 接入先導

此階段在 P21 空間評估已揭露並達工程門檻後設定，屬順序探索。使用原 P20 相同 9 片段、3 seeds（27 次）及 3 個無陰影對照，不換段、不刪缺測。

唯一科學變更是主移動鏈路的有效 radio 模型：P21 trace 302 選定 kernel_10 的空間殘差均值，加同一訓練 trace 上該模型剩餘殘差所估的 AR(1) 標準差/相關係數。距離 OLS 部分與 P20 相同；背景鏈路、流量、MAC、接收觀測、初始化均沿用 P20。將空間偏移先按來源位置每 0.1 秒計算，ns-3 對相鄰時間線性插值；這是明示的有限解析度近似。主 client 和共置 monitor 與 AP 間雙向共享同一有效偏移，其他链路不加它。

實測評估 RSSI 不作 ns-3 輸入。先固定所有空間偏移、訓練參數與 case。舊 4 工程 case 仍須通過，另驗證已知常數 +3 dB 和逐秒 +1 dB 的偏移能在逐幀接收 RSSI 中精確重現，再跑實測片段。

主比較沿用 P20 完整自有可用秒分布，逐段及 pooled 保留；另外在結果前明定相同可用秒 RSSI/busy 比較，與原結果並列。保留 data/beacon 主幀與 all-AP 候選，保留全部缺測比例。5 dB RSSI、0.05 busy/缺測差沿用 P20 工程線。空間改進不會替代 capture 及硬體 counter 證據，任何觀測語義未解即不宣布實測 posterior 就緒。

本輪不將「由資料擬合的 radio 模型」稱為獨立於量測的機理驗證。它是在訓練/評估分離條件下，檢查經驗空間模型是否改善固定封包模擬輸出的觀測分布。
