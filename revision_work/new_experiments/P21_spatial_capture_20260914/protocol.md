# P21：空間訊號與採集可用性檢查

2026-09-14。接續 P20 的限定探索，先固定本文件和程式，再產生評估結果。所有原始資料先前已作整體描述；本輪不得稱為從未接觸的確認試驗。P20、正文、回覆及 47 項審計均保留。

## 問題與可支持的結論

目標是檢查公開位置能否改善「有資料幀接收時的每秒 RSSI」預測，以及區分可觀察的接收狀態。原始 RSSI 來自公開量測，真值不以新模型輸出定義。兩個不可識別世界為「設備仍在收集但無幀」與「某個採集環節失效」；兩者均可能產生無 data、無 beacon、busy 未知的摘要。跨設備的同時接收可排除全系統同時停機，不能排除單一設備的採集中斷。

通過只支持局部空間條件模型值得進一步整合至 ns-3；不是原固定診斷器的實測後驗驗證，也不是原因分類準確率。改善物理鏈路預測不會自行補齊 C2/MAC/BLE/video 的同步觀測。

## 來源與分割

- 使用 P20 保存且已核雜湊的 VNC20 完整 CSV/README；公開記錄 https://zenodo.org/records/6884095。
- 主分析只取 802.11n / 2437 MHz；每 trace、每秒一列。nBytesReceived > 0 且 rssiMean > -100 才有 data RSSI；任何不一致須報出，不悄悄捨棄。
- trace 302 是唯一模型訓練來源。303/304 是同日未參與擬合的再評估；401–405 是另一採集日、未參與本輪擬合及選模的 radio 評估。第二日 AP 支承車輛不同。40x 的 n/ac busy 是估算，完全不作實測 busy 比較。
- 訓練 trace 全時間範圍等分 5 個連續區間。每折排除驗證區間及兩邊 60 秒的訓練資料；折內只用訓練部分拟合所有係數。只根據 5 折等權平均 MAE 選模型。不是隨機逐秒切分，允許使用其他時間走過的相同路段。

## 固定候選模型

共同基線是 OLS：RSSI = a + b log10(max(distance, 1 m))。比較：

1. 共同基線本身。
2. 基線加空間二次殘差項 x/100、y/100、(x/100)^2、xy/10000、(y/100)^2；殘差截距不懲罰，其他係數 L2 懲罰 1。
3. 基線加以公開 XY 計算的 Gaussian kernel 殘差均值，帶寬固定候選 10、25、50、100 m。分母加 10 個零殘差偽觀測，稀疏位置縮回基線。

不得用評估 RSSI、beacon、busy、吞吐或缺測模式產生預測；位置/距離只作已知場景條件。固定候選均報告，選定後即保存模型與選模結果雜湊，再評估 303–405。殘差量只作後續陰影模型診斷；本輪不為匹配測試分布而加入噪音。

## 指標、單位與推進門檻

- 主指標是每秒配對絕對誤差的均值 MAE（dB）；同時報 RMSE、bias、完整每 trace 指標。日內總結用 trace 等權平均，避免長 trace 自動決定全部結論。
- W1 只比較「預測條件均值的分布」與實測接收秒 RSSI，明示它不是帶隨機陰影及接收選擇的 ns-3 分布，不能與 P20 的 W1 直接作改善百分比。
- 不刪除不利 trace；403/404 即使短也保留。每 trace 列出資料可用秒、總秒、與訓練位置最近距離超過 25 m 的比例。缺測秒不被補為實際 RSSI，也不算成有效樣本。
- 描述性不確定性：按各 trace 起點的非重疊 60 秒區塊，在每 trace 內有放回抽樣 1000 次；固定 seed 210914，按 trace 等權重匯總 MAE 差。這是對現有路段時間相依的敏感度，不代表獨立採集日或 UAV 任務的總體信賴區間。
- 進入新 ns-3 空間實現的工程門檻：所選模型不是原基線；同日與跨日兩組的 trace 平均 MAE 各改善至少 10%；任一評估 trace 的 MAE 不惡化超過 20%。門檻是本輪工程選擇，無外部標準含義。失敗則保留全結果，轉查可量測的場景/遮擋/方向資訊，不在同一評估集再換模型。

## 缺測與來源核對

完整三種 Wi-Fi 均按 trace/systime 唯一鍵外連結，不按行索引。檢查 join 覆蓋和 1 秒間隔；列出 data/beacon/busy 可用性、互斥狀態、連續缺測區間及其是否到達 trace 尾端。

主條件：n 無 data、无 beacon 且 busy 缺測。對每秒報告 ac/ad 是否仍有 data/beacon、各 radio 的 UDP consumer 是否仍大於零、幾何是否仍有列。這些是正向觀測證據；所有零或 sentinel 不會被解讀為確證的採集停機。若 n 的 consumer > 0 但 capture 無幀，標為跨採集通道不一致，不能直接當作空口失聯。

僅對已知公開原作者來源作一次有界採集語義核對。新版 WiChoose 程式若沒有與 2019 archive 的可追溯聯繫，不用來證明原 counter/filter。保存讀取成功/失敗與未解欄位。

## 交付與推論門

輸出分割表、所有候選 CV 結果、訓練模型、全部評估預測/指標、缺測秒與連續區間、數值覆核、資料來源、可重現分析本及交接。數據品質檢查是此實驗的限定部分，不擴成新整體審稿審計。

推論鏈：公開來源及唯一鍵 → 接收/捕獲條件可用性 → 有效秒空間預測 → 分割後的誤差比較。最後一步不能跨到原因真值或原 DES 已校準。審稿人可能追問接收條件偏差、只兩個採集日的外推、counter 的精確定義；分別用全狀態分母、按日結果和來源核對處理，不用語言承諾代替證據。
